# YouTube Clone

This project is a simple HTML and CSS clone of the YouTube interface. It replicates the layout and visual aspects of YouTube without any functionality.

## Project Structure

```
youtube-clone
├── index.html        # Main HTML structure of the YouTube clone
├── styles
│   └── style.css     # CSS styles for the YouTube clone
└── README.md         # Documentation for the project
```

## How to View the Project

1. Clone the repository or download the project files.
2. Open the `index.html` file in your web browser.
3. You should see a layout that resembles the YouTube interface.

## Design Choices

- The layout is structured to include a header, sidebar, video thumbnails, and a footer.
- CSS is used to style the elements, ensuring that the colors and fonts are similar to those used by YouTube.
- The project is designed to be responsive, adapting to different screen sizes.

Feel free to modify the styles in `styles/style.css` to customize the appearance further!
